# 验证截图

这三个版本各自跑起来后的实际截图，用来对照确认「复刻」到底复刻的是哪一个形态。

| 目录 | 是什么 | 怎么来的 |
|---|---|---|
| `01-vue-webpack-local/` | Vue 2 + Webpack 版**本地构建** | 本仓库源码 `npm run build` 后本地起静态服务截的 |
| `02-old-site-90175/` | **`http://cuber.90175.com/` 线上站** | 直接访问截图。注意：它是旧版 Vue 实现，**不是上游最新代码** |
| `03-react-vite-local/` | React 19 + Vite 版**本地构建** | 上游 `master` 构建后本地起服务截的 |
| `04-react-vite-cheesefans/` | **上游最新线上站** <https://cuber.cheesefans.com> | 直接访问截图 |

## 怎么看出差别

`01` 和 `02` 长得一样（同一个 Vue 实现）：计时器是左上角**蓝色数字**，底部三个**独立图标**（骰子/剪贴板/退格）。

`03` 和 `04` 长得一样（同一个 React 实现）：计时器变成**白色药丸卡片**，底部图标集中进**一条白色圆角工具栏**，
图标风格也不同（lucide 的细线图标，而不是 Material 实心图标）。魔方本身的光照与描边也重做过。

`01-vue-webpack-local/` 里额外还有几张交互验证截图：

- `10-after-R1` / `10-after-R4` — 键盘按 `I`（=R）之后的状态
- `11-after-undo` — 撤销后
- `12-menu` — 展开菜单
- `20-algs-playing` — 公式库播放 F2L-01，实际执行 `U R U' R'`
- `30-director-typed` — 动画制作里输入动作脚本
- `40-solver-verified` — 求解器算完并应用解法后的复原状态
